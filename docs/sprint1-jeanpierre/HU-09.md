# HU-09 · Registrar la presentación de la declaración de un periodo

- [ ] 61 Análisis y diseño · [x] 62 Interfaz · [x] 63 API · [x] 64 Unitarias · [ ] 65 Integración

Reglas: solo desde `PENDIENTE`; fecha de declaración obligatoria, no futura ni anterior al periodo; número de
formulario obligatorio (máx. 30); monto determinado obligatorio y no negativo. Todo faltante se reporta junto.

> Depende de HU-07 (Ricardo). La obligación de esta rama es **provisional**.

## Caso de uso "Registrar declaración" (borrador)

Actor: Contador. Marca una obligación `PENDIENTE` como declarada con fecha, número de formulario y monto determinado.
Sin número de formulario no se acepta. La fecha y el formulario quedan consultables. HU-13 (Ricardo) espera `DECLARADO`.

## Diagrama de estados de la obligación (borrador)

```mermaid
stateDiagram-v2
    [*] --> PENDIENTE : HU-07 programa la obligación
    PENDIENTE --> DECLARADO : declarar(fecha, nº formulario, monto)
    PENDIENTE --> PENDIENTE : sin nº formulario (rechazado)
    DECLARADO --> [*] : HU-13 registra constancia de pago
```

| Método | Ruta |
