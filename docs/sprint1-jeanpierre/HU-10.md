# HU-10 · Variar la fecha de vencimiento programada

- [ ] 66 Análisis y diseño · [x] 67 Interfaz · [x] 68 BD · [x] 69 API · [x] 70 Unitarias

Reglas: todas o ninguna; se rechaza si la nueva fecha es anterior al periodo de alguna obligación o si alguna ya
está declarada. Cada fecha anterior queda en `vencimientos_historial`; misma fecha no genera historial.
`GET /api/tributario/obligaciones?clienteId=` es **provisional** (lista mínima hasta integrar HU-07).

> Depende de HU-07 (Ricardo). La obligación de esta rama es **provisional**.

## Caso de uso "Variar fecha de vencimiento" (borrador)

Actor: Contador. Selecciona una o varias obligaciones y una nueva fecha límite. Se guarda la fecha anterior en el historial.
Se rechaza (todas o ninguna) si la nueva fecha es anterior al periodo tributario de alguna obligación.

## Diagrama de secuencia (borrador)

```mermaid
sequenceDiagram
    actor C as Contador
    participant W as VencimientosPage
    participant API as ObligacionController
    participant S as ObligacionService
    participant DB as BD
    C->>W: selecciona obligaciones + nueva fecha
    W->>API: PATCH /obligaciones/vencimiento {obligacionIds, nuevaFecha}
    API->>S: cambiarVencimiento(dto)
    S->>DB: buscar obligaciones
    alt nuevaFecha < periodo de alguna
        S-->>API: ValidationException
        API-->>W: 400 {mensaje}
    else válida
        loop cada obligación
            S->>DB: INSERT vencimientos_historial(anterior, nueva)
            S->>DB: UPDATE fecha_vencimiento
        end
        API-->>W: 200 obligaciones actualizadas
    end
```
